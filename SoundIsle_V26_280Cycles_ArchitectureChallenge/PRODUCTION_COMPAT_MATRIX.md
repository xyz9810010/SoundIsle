# SoundIsle Production Compatibility Matrix

Record evidence, not assumptions.

Dimensions:
- SoundIsle version/build
- HarmonyOS device/model and OS build
- Navidrome/server version
- OpenSubsonic capability result
- direct/reverse-proxy/subpath deployment
- Wi-Fi/cellular/high-latency/lossy network
- audio codec/container
- library size class
- playback/background/download result
- known limitation/workaround

A server version must not be used as a substitute for capability detection.
