# SoundIsle — Start Here

1. `MASTER_PLAN.md`
2. `DOCUMENT_PRECEDENCE.md`
3. `CURRENT_MILESTONE.md`

## Then Read by Task
Use `TASK_SPEC_MAPPING.md` to load only the normative files required by the current task.

## Never Read by Default

Archive files explain history; they are not current specifications.

## If Unsure
- terminology → `GLOSSARY.md`
- what counts as done → `DEFINITION_OF_DONE.md`
- architecture ownership → `SPEC_OWNERSHIP.md`
- document conflict → `DOCUMENT_PRECEDENCE.md`
