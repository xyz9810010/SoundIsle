# SoundIsle Task Risk Levels

## S — Small
Examples: copy change, isolated visual spacing, non-behavioral refactor.
Read active core + 0–2 direct task specs.

## M — Medium
Examples: repository query, settings behavior, new screen state.
Read active core + mapped feature contracts/tests.

## L — Large / High Risk
Examples: playback, migration, credentials, downloads, provider contract, background lifecycle.
Read active core + all directly mapped normative specs and applicable test/release documents.

Risk level changes documentation/test burden; it never permits violating SYSTEM_INVARIANTS or security/data rules.
