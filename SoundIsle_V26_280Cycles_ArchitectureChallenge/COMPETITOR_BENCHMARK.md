# SoundIsle Competitor Benchmark

Benchmarking is about usable quality, not checkbox count.

## Levels
`EXISTS | WORKS | RELIABLE | PLEASANT`

A feature counts as “not worse” only when it reaches at least RELIABLE for the supported scope.

| Capability | StreamMusic benchmark | SoundIsle V1 target | Verification |
|---|---|---|---|
| Navidrome/Subsonic connection | Required | First-Class | Real Navidrome integration |
| Library browsing/search | Required | Reliable | Large-library + real server tests |
| Playback/seek/queue | Required | Reliable | automated + device |
| Background/lock-screen | Required | Reliable | device |
| Lyrics | Required | Reliable where source exists | provider/device UX |
| Download/offline | Required | Reliable | offline/red-team |
| Transcode/original quality | Required | Reliable | AudioSource evidence |
| ReplayGain | Desired | Verify before release | audio test |
| Gapless | Desired | Best-effort first; no false claims | continuous-album test |
| Multiple servers/providers | Benchmark supports several | Navidrome First-Class; others staged | provider-by-provider |
| Diagnostics | Improvement area | Strong sanitized diagnostics | QA/support review |

Do not copy StreamMusic proprietary implementation, assets or branding.
